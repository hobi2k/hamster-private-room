# 페이지 삭제 버튼 추가

## 개요
현재 선택한 한 페이지를 헤더에서 바로 삭제할 수 있는 버튼을 추가했다. 기존 다중 선택 삭제 로직을 단일 본문 페이지와 표지까지 확장하고, 모바일에서 헤더 도구가 서로 겹치지 않도록 배치를 정리했다.

## 주요 변경사항
- 개발한 것: 단일 페이지 및 표지 삭제 버튼
- 수정한 것: 단일 페이지 삭제 시 본문, 이미지, 말풍선, 꼬리말과 뒤 페이지 번호를 함께 정리
- 개선한 것: 마지막 본문 한 장 삭제 시 편집 가능한 빈 페이지 유지 및 전용 안내 문구 표시
- 개선한 것: 모바일 햄스터 애니메이션을 헤더 아래로 이동해 삭제·추가 버튼 가림 방지

## 결과
- 표지 삭제 및 실행 취소 확인
- 중간 페이지 삭제 후 번호 재정렬 및 실행 취소 확인
- 마지막 본문 페이지 비우기 및 실행 취소 확인
- 다중 선택 페이지 삭제 회귀 확인
- 모바일 390x844 및 데스크톱에서 버튼 겹침 없음 확인
- `npm run typecheck` 통과
- `npm run build` 통과
