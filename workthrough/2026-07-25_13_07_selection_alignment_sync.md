# 본문 선택과 문단 정렬 동기화

## 개요
화면에 선택 영역이 보이는데도 정렬이 거부되거나 이전 문단이 정렬되던 문제를 수정했다. 브라우저의 실제 선택 범위를 버튼을 누르는 순간 읽고, 정렬 마크는 선택한 문단 범위만 교체하도록 변경했다.

## 주요 변경사항
- 수정한 것: 마우스·터치 선택 범위를 DOM에서 직접 읽어 첫 클릭 정렬에 사용
- 수정한 것: 커서만 있거나 다른 UI로 이동한 뒤에는 이전 선택을 재사용하지 않도록 정리
- 개선한 것: 큰 정렬 범위 안의 한 문단만 바꿔도 앞뒤 문단 정렬을 보존
- 개선한 것: 모바일 메뉴와 하단 원고 탭을 열 때 선택 범위 유지
