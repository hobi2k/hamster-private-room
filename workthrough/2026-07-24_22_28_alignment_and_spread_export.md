# 정렬 개행과 양면 PNG 저장 수정

## 개요
문단 정렬 경계의 개행이 편집 종료 후 문단 여백으로 바뀌던 문제를 수정했다. 양면 내보내기는 표지와 1쪽부터 순서대로 묶고, ZIP 대신 선택한 폴더에 PNG 파일을 직접 저장하도록 변경했다.

## 주요 변경사항
- 정렬 블록 경계용 개행과 사용자가 입력한 개행을 분리해 포커스 전후 간격 유지
- 양면 순서를 `표지+1쪽`, `2쪽+3쪽`으로 수정하고 마지막 홀수 쪽은 낱장 처리
- 여러 장 저장 시 폴더 선택 API를 우선 사용하고 PNG를 개별 파일로 기록
- 폴더 선택 API가 없는 브라우저는 개별 PNG 다운로드로 대체
- 내보내기 안내 문구와 취소 상태 처리 개선

## 결과
- 타입 검사 통과
- 단위 테스트 34개 통과
- 배포 빌드 성공
- 포커스 전후 텍스트 위치와 높이 변화 0px 확인
