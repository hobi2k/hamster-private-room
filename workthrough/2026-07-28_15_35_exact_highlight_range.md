# 형광펜 선택 범위 고정

## 개요
글자 효과 적용 뒤 본문 DOM이 다시 그려질 때 브라우저 선택 범위가 오래된 노드를 가리켜 앞 문장까지 효과가 번지던 문제를 수정했다. 화면에서 선택한 문자열과 저장할 본문 범위를 대조하고, 다시 그린 본문에도 같은 선택 범위를 복원한다.

## 주요 변경사항
- 수정한 것: 형광펜·보조색을 연속 적용해도 처음 선택한 범위를 유지
- 개선한 것: 접히거나 오래된 브라우저 선택 좌표 대신 검증된 저장 범위를 사용
- 추가한 것: `흐트러지지 않았다.` 앞 문장에 배경색·글자색이 번지지 않는 회귀 테스트

## 결과
- 전체 테스트 49개 통과
- 타입 검사 및 프로덕션 빌드 성공
- 프로덕션 미리보기 콘솔 오류 없음

## 다음 단계
- 실제 사용자 입력 조합을 포함한 브라우저 E2E 테스트를 자동화해 선택·꾸미기·내보내기 흐름을 지속 검증한다.
