# 원고 이미지와 내보내기 개선

## 개요
원고 편집과 책 정보 설정을 분리하고, 본문 흐름 안에 이미지를 삽입해 확대·이동할 수 있도록 확장했다. 형광펜 편집과 선택 서식 제거, 기본 조판, 여러 PNG 직접 다운로드도 함께 개선했다.

## 주요 변경사항
- 개발한 것: 본문 흐름 이미지 삽입, 정렬, 확대, 상하좌우 초점 이동
- 수정한 것: 620px 기본 지면, 기본 양쪽 정렬, 표지·꼬리말 제목/부제 글꼴
- 개선한 것: 형광펜 색/불투명도 실시간 팝업과 선택 영역 서식만 제거
- 개선한 것: 폴더 선택창 없이 양면/낱장 PNG를 다운로드 폴더로 직접 저장
- 수정한 것: 선택 DOM이 접힌 뒤에도 마지막 유효한 텍스트 범위를 유지

## 결과
- 단위 테스트 45개 통과
- TypeScript 검사 및 프로덕션 빌드 성공
- 데스크톱·390px 모바일 시각 및 상호작용 검증 완료
- 양면 펼침 PNG 파일 생성과 페이지 짝 확인 완료
