# 북메이커 Pro 기능 이식

## 완료한 작업

- 자유 페이지 높이, A4/A5/B6 용지 비율, 단어/글자 줄바꿈, 선택 페이지 텍스트 높이 맞춤을 추가했다.
- 페이지별 단색/그라데이션 배경과 제목·부제목·책 이름·캐릭터 이름 및 개별 서식을 추가했다.
- 밑줄·취소선, `**굵게**`, `*강조*`, 따옴표·괄호 스마트 서식과 확장 구분선을 추가했다.
- 자유 이미지의 채우기/맞춤/늘리기, 위치 힌트, 흑백, 투명도, 다크 오버레이를 추가했다.
- 본문 이미지의 틀 높이와 투명도 조절을 추가했다.
- 내장/사용자 스티커의 삽입·이동·크기·회전·반전·삭제 기능을 추가했다.
- 위험 요소를 제거하는 HTML 카드 삽입, 미리보기, 정렬, 너비/배율, 삭제 기능을 추가했다.
- 멤버 URL 사진, 사진 없는 프로필의 배경/이니셜, 이름색/외곽선/숨김을 추가했다.
- 말풍선별 4색, 이어 말풍선, 앞/뒤 본문 삽입, 선택 페이지 고정 힌트를 추가했다.
- 새 필드를 기존 `.hamsterbook`과 브라우저 저장 데이터에서 안전하게 기본값 보정하도록 정규화했다.

## 버그 수정 및 안정화

- 페이지 경계 오프셋에서 말풍선이 선택 페이지보다 앞쪽으로 역류하지 않도록 최소 페이지 힌트를 페이지네이터에 추가했다.
- 페이지 끝 커서에 추가한 말풍선은 다음 페이지에서 시작하고, 남은 본문은 같은 페이지의 말풍선 아래 이어지도록 했다.
- 도구/검사 패널을 눌러도 본문 커서 선택 범위가 사라지지 않도록 보존 범위를 넓혔다.
- HTML 카드의 `script`, 이벤트 속성, 위험 URL을 제거해 저장·렌더링 시 스크립트가 실행되지 않게 했다.
- PNG 내보내기 때 스티커/HTML 카드 선택 테두리와 조작 핸들이 포함되지 않게 했다.
