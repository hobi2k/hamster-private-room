# 누락 기능 보완과 편집기 UI 개선

## 개요
북메이커 기능 이식 결과를 사용자 요구사항과 다시 대조해 빠져 있던 홈 이동, 색상 기록, 멤버 색상 전파, HTML 카드 배치, 애니메이션 GIF 내보내기를 보완했다. OriginKit의 명확한 계층과 짧은 상호작용 모션을 참고하되 기존 크림·브라운 햄스터 디자인은 유지했다.

## 주요 변경사항
- 개발한 것: 현재 페이지의 GIF 스티커·사진을 실제 프레임으로 합성하는 GIF 내보내기
- 개발한 것: 모든 색상 컨트롤에서 공유하는 최근 색·추천 색·고정 색 보관함
- 수정한 것: 멤버 말풍선색·글자색 변경이 연결된 기존 말풍선 전체에 즉시 반영되지 않던 문제
- 개선한 것: HTML 카드 자동/고정 높이, 가로·세로 위치, 직접 드래그 이동
- 개선한 것: 왼쪽 로고 홈 이동, 패널 전환·선택·버튼·팝오버 모션과 키보드/저감 모션 대응
- 수정한 것: 좁은 다열 컨트롤에서 색상 보관함이 레일 아래로 잘리던 레이아웃 문제
