# 자동 페이지 커서와 본문 잘라내기 수정

## 개요
본문이 다음 페이지로 분할될 때 커서가 문장 앞쪽으로 이동하거나 본문이 중복되는 문제를 수정했다. 말풍선 앞뒤의 본문을 직접 편집하고 잘라낼 때 말풍선 앵커와 화면 배치가 함께 따라오도록 편집 흐름도 보강했다.

## 주요 변경사항
- 수정한 것: React 재렌더링이 활성 `contentEditable` DOM과 선택 영역을 덮어쓰지 않도록 DOM 동기화 책임을 분리
- 수정한 것: 입력 직후 포커스 해제 과정에서 같은 본문 조각이 다시 저장되어 문장이 늘어나던 문제 제거
- 개선한 것: 연속 입력과 여러 줄 붙여넣기에서 현재 편집 범위의 끝을 추적해 중복 삽입 방지
- 개선한 것: 본문 잘라내기 후 커서 복원, 말풍선 앵커 이동, 실행 취소/다시 실행 연결
- 개선한 것: 첫 말풍선 선택 테두리와 위치 버튼을 말풍선 안쪽에 배치해 페이지 경계 잘림 방지

## 결과
- 자동 분할 8페이지, 본문 3,400자와 마지막 커서 절대 위치 3,400 일치
- 마지막 페이지 연속 입력, 전체 잘라내기, 실행 취소 동작 확인
- 두 말풍선 사이 직접 입력 및 잘라내기 후 앵커 이동과 비활성 간격 확인
- 모바일 390x844에서 옵션 패널 오버레이와 내부 스크롤 영역 확인
- `npm run typecheck` 통과
- `npm run build` 통과
