# PNG 선택 오버레이 제거

## 개요
본문을 드래그한 상태로 PNG를 저장하면 브라우저의 파란 선택 배경과 선택 글자색이 결과 이미지에 섞일 수 있던 문제를 수정했다. 모든 이미지 캡처 경로에서 포커스와 네이티브 선택 범위를 제거한 뒤 한 프레임 후 렌더링한다.

## 주요 변경사항
- 수정한 것: 낱장·선택 페이지·양면·클립보드 복사 전에 브라우저 선택 제거
- 개선한 것: 내보내기 중 페이지의 `::selection` 페인팅과 텍스트 선택 차단
- 추가한 것: 포커스 해제와 `removeAllRanges()` 호출 회귀 테스트

## 결과
- 전체 테스트 50개 통과
- 타입 검사 및 프로덕션 빌드 성공
- 실제 PNG에서 무효과 앞 문장과 형광펜·글자색 적용 뒷 문장이 정확히 분리됨

## 다음 단계
- 선택 범위가 남은 상태의 낱장·양면·복사 내보내기를 브라우저 E2E로 계속 자동화한다.
