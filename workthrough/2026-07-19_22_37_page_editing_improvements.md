# 페이지 편집 기능 개선

## 개요
여러 페이지를 골라 한 번에 삭제하는 흐름과 원고 색상 도구, 이미지 자동 채움, 프로필 사진 크롭을 추가했다. 편집 중에도 글자 효과가 보이도록 본문 편집 레이어를 개선하고 글자 크기 축소 시 페이지가 다시 촘촘하게 채워지도록 재조판 계산을 수정했다.

## 주요 변경사항
- 개발한 것: Ctrl/Command 다중 페이지 선택·삭제, 프로필 사진 확대·이동 크롭
- 수정한 것: 편집 중 스마트/수동 글자 효과 표시와 효과 재클릭 해제
- 개선한 것: 보조색·형광펜 원고 메뉴 이동, 이미지 비율 유지 전체 채움, 최대 500% 확대
- 개선한 것: 실제 페이지 영역과 일치하는 자동 페이지 분할

## 결과
- 빌드와 타입 검사 통과
- 다중 선택 삭제·실행 취소, 편집 중 서식, 데스크톱·모바일 화면 검증 통과
- 가로·세로 이미지 채움과 글자 크기별 재조판 계산 검증 통과

## 다음 단계
- 실제 사용자 사진과 다양한 종횡비 이미지로 크롭 감각값을 추가 조정할 수 있다.
- 다중 페이지 선택 범위를 Shift 클릭으로 연속 선택하는 기능을 확장할 수 있다.
