# 표지 제목색 설정

## 개요
표지 제목에만 별도 색을 지정할 수 있는 옵션을 추가했다. 지정하지 않으면 그림 표지는 흰색, 글자 표지는 본문색을 따르는 기존 자동색 동작을 유지한다.

## 주요 변경사항
- 표지 설정에 `표지 제목색` 선택기와 `자동색` 초기화 버튼을 추가했다.
- 사용자 지정색을 작업 파일, 자동 저장, 사용자 테마에 함께 보존한다.
- 이전 작업 파일에는 새 값이 없어도 기본 자동색으로 열리도록 호환성을 유지했다.

## 결과
- 프로덕션 빌드 성공
- 그림 유무별 자동색, 사용자 지정색, 자동색 복귀 검증 통과
- 자동 저장 후 새로고침 및 모바일 UI 검증 통과
