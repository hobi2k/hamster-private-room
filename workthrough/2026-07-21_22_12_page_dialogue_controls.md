# 페이지 추가와 말풍선 정렬 개선

## 개요
자동 분할이 늦거나 부족할 때 편집 가능한 빈 페이지를 직접 추가할 수 있게 했다. 말풍선은 자유 드래그 대신 좌우 자동 정렬과 위·아래 순서 이동을 사용하며, 내용 기반 너비와 글자 크기·이름 표시 옵션을 추가했다.

## 주요 변경사항
- 개발한 것: 수동 페이지 구분자 기반 페이지 추가와 저장·불러오기 호환
- 개선한 것: 연속 말풍선 순서 교환, 6% 행 이동, 좌우 가장자리 자동 정렬
- 개발한 것: 가장 긴 줄 기준 자동 너비, 대사·보조문장 크기, 이름 표시 토글
- 추가한 것: 햄스터 얼굴 PNG 파비콘
- 보강한 것: 수동 페이지가 포함된 다중 페이지 삭제 범위 병합

## 결과
- ✅ TypeScript 및 Vite 프로덕션 빌드 성공
- ✅ 수동 페이지 추가·편집 동작 테스트 통과
- ✅ 말풍선 순서·행 이동·자동 너비 경계값 테스트 통과
- ✅ 개발 서버와 파비콘 HTTP 200 확인
