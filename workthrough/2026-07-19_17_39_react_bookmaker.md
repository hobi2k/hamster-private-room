# React 북메이커 전환

## 개요
단일 HTML 시안을 참고 자료로 보존하고 실제 서비스 코드를 React 19, TypeScript, Vite 구조로 새로 만들었다. 새 책, 최근 작업, 파일 불러오기가 있는 메인 서재와 모바일 전용 편집 시트, OpenRouter 생성 햄스터 스프라이트를 포함했다.

## 주요 변경사항
- 개발한 것: 자동 페이지 분할, 테마, 이미지 변형, 스마트 하이라이트, 꼬리말, 저장과 PNG 내보내기
- 개선한 것: 데스크톱 편집 패널과 390px 모바일 하단 도구 흐름
- 추가한 것: 큰 6프레임 투명 햄스터 보행 애니메이션과 GitHub Pages Actions 배포

## 결과
- ✅ TypeScript 타입 검사 성공
- ✅ Vite 프로덕션 빌드 성공
- ✅ 1440×900, 390×844 브라우저 화면 검증
- ✅ 긴 원고 5페이지 생성 후 짧은 원고 1페이지 축소 검증
- ✅ 0.26초 간격 스프라이트 프레임 transform 변경 검증
