# 편집기 경계 사례 수정

## 개요
본문 선택 중 글자가 사라지는 문제와 프로필 사진 자르기의 축 제한을 수정했다. 홀수 쪽 양면 내보내기, 표지 이미지 투명도, 모바일 옵션 패널의 레이어 순서도 함께 보완했다.

## 주요 변경사항
- 본문 편집기 재진입 시 이전 스크롤 오프셋을 제거하고 클릭 위치에 커서를 배치했다.
- 프로필 원본 비율을 저장해 확대된 실제 프레임 기준으로 상하좌우 이동 범위를 계산했다.
- 양면 펼침에서 마지막 홀수 쪽을 낱장 PNG로 저장하도록 변경했다.
- 표지 글자를 이미지 레이어보다 위에 두되 페이지 내부에 격리해 모바일 옵션 패널을 가리지 않게 했다.

## 결과
- 빌드 및 타입 검사 성공
- 본문 스크롤 719px 이후 재진입 및 드래그 선택 1-69에서 글자 유지 확인
- 세로·가로 프로필 사진 200% 확대 후 상하좌우 이동 확인
- 표지 이미지 투명도 0.5에서 글자 투명도 1.0 유지 확인
- 3쪽 내보내기에서 1840x1302 펼침 PNG와 920x1302 낱장 PNG 생성 확인
- 390px 모바일 화면에서 옵션 패널이 페이지 콘텐츠보다 위에 표시됨을 확인
