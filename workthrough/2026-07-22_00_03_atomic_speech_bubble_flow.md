# 말풍선 본문 흐름 통합

## 개요
별도 `말풍선 사이 글` 모델과 편집 UI를 제거하고, 말풍선을 본문 안의 원자 블록처럼 배치하도록 변경했다. 사용자는 페이지에서 말풍선 앞·사이·뒤에 직접 입력할 수 있으며 텍스트와 말풍선은 함께 자동 페이지 분할된다.

## 주요 변경사항
- 말풍선에 본문 `anchor`를 추가하고 이전 저장 데이터와 `dialogueTexts`를 자동 변환
- 본문을 여러 `contenteditable` 구간과 말풍선 블록의 단일 흐름으로 렌더링
- 같은 위치의 연속 말풍선도 한 개씩 다음 페이지로 넘기는 블록 단위 페이지 계산 추가
- 대사 직접 편집, 줄바꿈, 선택 서식, 실행 취소에서 DOM이 사라지던 편집 동기화 문제 수정
- 별도 사이 글 설정과 관련 타입·스타일·간격 계산 제거

## 결과
- ✅ TypeScript 검사 및 Vite 프로덕션 빌드 성공
- ✅ 서로 다른 멤버 2개 사이 직접 입력, 이동·취소·재실행, 삭제·복원 확인
- ✅ 빈 원고의 긴 말풍선 10개가 `3/3/3/1`개로 4쪽에 분리되고 모든 쪽 넘침 `0` 확인
- ✅ 포커스 전후, 저장 후 새로고침, 문단 간격, 대사 줄바꿈, 서식 적용·해제 확인
- ✅ 390px 모바일에서 가로 넘침 `0`, 본문·말풍선 충돌 없음, 옵션 패널이 본문 위에 정상 표시됨
