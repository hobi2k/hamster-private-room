# 본문 입력 안정화와 구분선

## 개요
본문 편집기의 붙여넣기, 개행, 커서 복원, 선택 및 잘라내기 흐름을 정리했다. 구분선 4종과 말풍선 좌우 전환 기능도 추가하고 페이지 흐름, 저장 복원, 모바일 화면까지 확인했다.

## 주요 변경사항
- 개발한 것: 실선, 점선, 다이아, 점 장식 구분선과 색상 편집 및 삭제 기능
- 개발한 것: 선택한 말풍선을 즉시 좌우로 바꾸는 버튼
- 수정한 것: 붙여넣기 서식을 제거하고 입력 직후 페이지 나눔과 커서 이동이 반영되도록 개선
- 수정한 것: 개행 뒤 커서 위치, 키보드 선택 유지, 본문 잘라내기 및 새 페이지 붙여넣기 오류
- 개선한 것: 구분선과 말풍선을 같은 본문 흐름 블록으로 계산하고 페이지 하단 여유를 확보
