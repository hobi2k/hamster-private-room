# 말풍선 페이지 고정과 개행 커서 복구

## 개요
커서 없이 1페이지에 추가한 말풍선이 다음 페이지로 넘어가고, 말풍선 경계에서 개행한 뒤 한글 입력의 커서가 흔들리던 문제를 수정했다. 페이지 끝의 배타적 경계를 기본 앵커로 쓰던 동작과 개행용 커서 표식 내부에 실제 글자가 중첩되던 동작을 함께 바로잡았다.

## 주요 변경사항
- 수정한 것: 말풍선·구분선·본문 이미지의 기본 삽입 앵커를 선택 페이지 내부로 고정
- 개선한 것: 말풍선 직전 편집 구간이 끝 커서를 직접 소유하도록 경계 판정 보강
- 개선한 것: 개행 커서 표식 뒤에 실제 입력을 배치해 연속 `Enter`에서 표식이 중첩되지 않도록 변경
- 추가한 것: 페이지 경계 삽입 앵커와 흐름 블록 직전 커서 복구 회귀 테스트

## 결과
- 타입 검사, 전체 테스트 54개, 프로덕션 빌드 및 diff 검사 통과
- 실제 브라우저에서 커서 없이 추가한 말풍선이 1페이지와 2페이지에 각각 유지됨
- 말풍선 앞 연속 개행·한글 입력·포커스 해제 뒤에도 두 줄의 문자 배열과 512px 편집 폭이 유지됨
- 브라우저 오류 및 경고 로그 없음
