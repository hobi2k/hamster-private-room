# 본문 편집기와 PNG 내보내기 종합 안정화

## 개요
문단 정렬 때문에 본문 편집기가 여러 조각으로 나뉘던 구조를 하나의 편집 흐름으로 통합했다. 긴 붙여넣기, 자동·수동 페이지 경계, 개행 삭제, 말풍선 혼합 배치와 양면 PNG 내보내기를 실제 브라우저에서 조합 검증했다.

## 주요 변경사항
- 수정한 것: 선택 범위 보존, 단일 개행 유지, 문단 정렬 후 줄 합침·가짜 여백 제거
- 수정한 것: 페이지 경계 Backspace/Delete 범위 제한과 빈 커서 앵커 예외 방어
- 개선한 것: 폴더 권한 실패와 무관하게 PNG를 먼저 준비하고 파일별 저장을 제공
- 개선한 것: 양면 펼침을 `표지-1쪽`, `2-3쪽` 순서로 묶고 마지막 홀수 쪽은 낱장 PNG로 유지
- 검증한 것: 긴 입력 즉시 페이지 분할, 커서 복원, 실행취소·다시실행, 페이지 추가·삭제, 교차 멤버 말풍선 비겹침과 사이 본문 입력
