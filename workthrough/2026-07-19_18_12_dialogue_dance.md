# 말풍선과 정면 춤 햄스터

## 개요
멤버 프로필 기반 말풍선 편집 기능을 추가하고 작업 파일을 `.hamsterbook`으로 정리했다. 햄스터는 투명 배경의 정면 춤 6프레임으로 교체하고 모든 프레임의 중심과 발 기준선을 자동 정렬했다.

## 주요 변경사항
- 개발한 것: 멤버 이름, 프로필 사진, 말풍선과 글자 색상, 대사와 보조 문장, 페이지 위 드래그 이동
- 개선한 것: 프로필 사진 삭제 시 아바타와 꼬리가 사라지는 텍스트 전용 말풍선
- 수정한 것: 여섯 프레임 중심을 `127.5~128px`, 발 기준선을 `334px`로 통일해 루프 점프 제거
- 변경한 것: 사용자 저장 파일은 `.hamsterbook`으로 제공하고 기존 JSON 파일 불러오기는 호환 유지
- 정리한 것: 메인과 편집기의 메타 설명 문구 제거, 모바일 도구막대 7개 항목 대응

## 결과
- Vite 프로덕션 빌드 성공
- 데스크톱과 모바일 브라우저 화면 검증
- 사진 없는 말풍선 생성과 아바타 미출력 검증
- 스프라이트 RGBA, 투명 RGB 잔여물, 중심선, 기준선 검증 통과
