# 말풍선 사이 글 배치

## 개요
말풍선을 위아래로 조정해 실제 여유 공간을 만든 뒤에만 본문형 글을 사이에 추가할 수 있게 했다. 사이 글도 말풍선과 같은 세로 배치 계산에 포함해 멤버 조합과 문장 길이에 관계없이 서로 침범하지 않도록 했다.

## 주요 변경사항
- 개발한 것: 선택한 말풍선 뒤에 사이 글 추가, 직접 수정, 색상·기울임 변경, 삭제 기능
- 개선한 것: 실제 렌더링 높이와 다음 요소 위치를 기준으로 추가 가능 여부 판정
- 수정한 것: 페이지 삭제, 말풍선 삭제, 저장 슬롯, 실행 취소에서 사이 글 데이터도 함께 처리
- 개선한 것: 모바일 설정창 내부 스크롤과 페이지 직접 편집 지원
