# 햄스터의 집 — 리디자인 구현 가이드 (for Codex)

`햄스터의 집.dc.html` 시안을 **기존 React 코드베이스(`src/`)** 에 옮기기 위한 실무 가이드입니다.
컨셉: **포근한 굴/둥지** — 나무·이불·해바라기씨. 기능은 그대로, 껍데기(비주얼·무드·말투·인터랙션)만 새로 입힙니다.

> 원칙
> 1. **기능·상태·데이터 구조는 손대지 않는다.** `App.tsx` 상태머신, `pagination.ts`, `export.ts`, `themes.ts`, `types.ts`는 유지.
> 2. **바꾸는 건 `styles.css` 토큰과 클래스, 컴포넌트의 마크업/문구뿐.**
> 3. 6프레임 햄스터 스프라이트(`hamster-walk.png`)와 `@keyframes hamster-dance`, 4개 지면 테마는 그대로.

## 1. 디자인 토큰 — `src/styles.css` `:root` 교체

기존 `:root` 변수(차가운 세이지+테라코타)를 **따뜻한 굴 톤**으로 교체하고 신규 토큰을 추가합니다.

```css
:root {
  font-family: "Pretendard", sans-serif;
  color: #42301f;
  background: #efe0c2;

  /* 종이·표면 */
  --paper: #fcf5e6;        /* 카드·페이지 종이 */
  --paper-2: #f7edd7;      /* 패널(인스펙터) 표면 */
  --surface: #f7edd7;      /* (구 --surface 대체) */
  --surface-strong: #ffffff;
  --sand: #efe0c2;         /* 굴 벽 / 작업공간 배경 */
  --sand-2: #e7d3ac;

  /* 나무 / 잉크 */
  --wood: #38291b;         /* 도구막대(구 --rail) */
  --wood-2: #291c11;
  --rail: #38291b;         /* (구 --rail 대체) */
  --ink: #42301f;          /* 본문 글자 */
  --ink-soft: #8a755b;     /* 보조 글자(구 --muted) */
  --muted: #8a755b;
  --line: #e7d5ad;         /* 얇은 경계선 */

  /* 강조 */
  --honey: #eaa53c;        /* 1차 강조 = 램프/선택/활성 (햄스터 털색) */
  --honey-deep: #d5842a;
  --honey-soft: #fbe6bd;
  --clay: #cf6440;         /* 2차 강조 = 인용/포인트(구 --accent) */
  --accent: #cf6440;
  --accent-soft: #f6ddd3;
  --blush: #eca79c;        /* 말풍선/볼터치 핑크 */
  --leaf: #7f9553;         /* 새싹/저장 완료 그린(구 --teal 대체) */
  --teal: #7f9553;
  --yellow: #eaa53c;
  --glow: #fff4dc;         /* 램프 글로우 */

  /* 라운드: 기존 4px → 포근하게 키움 */
  --radius-sm: 10px;
  --radius-md: 13px;
  --radius-lg: 18px;
  --radius-pill: 999px;

  /* 부드러운 그림자(굴의 깊이감) */
  --shadow-card: 0 4px 12px rgba(90,68,40,.06);
  --shadow-float: 0 12px 26px rgba(90,68,40,.16);
}
```

기존 코드가 `var(--accent)`, `var(--teal)`, `var(--rail)`, `var(--surface)`, `var(--muted)`, `var(--line)`를 이미 참조하므로 위처럼 **같은 이름을 재정의**하면 대부분 자동 반영됩니다. 그 위에 신규 토큰만 각 클래스에서 사용.

## 2. 폰트 로딩 — `src/styles.css` 상단 `@import`

기존 import에 **Jua(라운드 디스플레이)** 와 **Gaegu(손글씨 말투)** 추가. RIDIBatang은 CDN이 불안정하니 **Noto Serif KR 폴백**을 항상 뒤에 붙입니다.

```css
@import url("https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css");
@import url("https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_twelve@1.0/RIDIBatang.css");
@import url("https://fonts.googleapis.com/css2?family=Jua&family=Gaegu:wght@300;400;700&family=Noto+Serif+KR:wght@400;600;700&display=swap");
```

**역할 분담(4단계)**
| 폰트 | 용도 |
|---|---|
| `"Jua"` | 큰 제목, 브랜드 워드마크, 도구/패널 헤더, 액션 카드 타이틀 |
| `"Gaegu"` | 햄스터 말투 마이크로카피 — 토스트, 마스코트 말풍선, 카드 서브텍스트, 패널 힌트 |
| `"Pretendard"` | 모든 기능 UI(라벨, 입력, 버튼, 메타) |
| `"RIDIBatang", "Noto Serif KR", serif` | 책 본문/표지 (지면) — **여기만 세리프** |

> 책 본문 폰트스택은 반드시 폴백 포함: `font-family: "RIDIBatang", "Noto Serif KR", serif;`
> (`BookCanvas`의 `--page-font` 계산부에도 동일하게 폴백 추가.)

## 3. 화면별 구현 가이드 (파일 매핑)

| 영역 | 파일 | 핵심 변경 |
|---|---|---|
| 홈 | `HomeScreen.tsx` + `.home-*` | 굴 아치 무대 + 램프/책장/러그/씨앗, 카피·카드 리디자인 |
| 도구막대 | `ToolRail.tsx` + `.tool-*`, `.brand-mark` | 호두나무 톤, 꿀색 활성바, 씨앗 브랜드마크 |
| 인스펙터 | `Inspector.tsx` + `.panel-*`, `.inspector-section`, `.field` | 크림 패널 + 라운드 카드형 섹션 |
| 책 지면 | `BookCanvas.tsx` + `.book-page` | **내부 로직 유지**, 선택 아웃라인 `--honey`, 그림자만 부드럽게 |
| 마스코트 | `HamsterMascot.tsx` + `.mascot` | 말풍선 폰트 `Gaegu`, 나머지 유지 |
| 워크스페이스 헤더 | `App.tsx` + `.workspace-header` | 홈버튼 옆 라운드 톤, 저장상태 아이콘 색 `--leaf` |

### 3-1. 홈 (`HomeScreen.tsx` / `.home-*`)
- 배경: `radial-gradient(125% 92% at 50% -12%, #fff7e6, #f4e7ca 44%, #e7d2a6)` (따뜻한 굴 입구).
- **굴 무대(아치)**: 새 래퍼 하나 추가.
  - 컨테이너 `border-radius: 48% 48% 20px 20px / 40% 40% 20px 20px`, 안쪽 그림자로 깊이.
  - 상단 중앙 **램프**(끈+갓+`radial-gradient` 글로우, `@keyframes glowpulse`), 그 아래에 기존 `.home-hamster-strip` 배치.
  - 좌측 **책장**(작은 색색 책등 rect들, 살짝 회전), 바닥 **나무 밴드 + 원형 러그**(`repeating-radial-gradient`).
  - ⚠️ 햄스터 뷰포트에 **`overflow: hidden` 필수** (없으면 6프레임 다 보임 — 실제로 이 버그가 있었음).
- **떠다니는 해바라기씨**: 작은 `span` 4개, `@keyframes seedfloat`으로 위아래.
- 헤더: 브랜드마크(꿀색 라운드 + 굴 입구 모양)와 `햄스터의 집`(Jua) + `포근한 굴 속 문장 작업실`(Gaegu). 우측 필 `씨앗 모으듯, 문장 모으기`.
- 3개 액션 카드(`.home-action`): 라운드 `--radius-lg`, hover 시 `translateY(-3px)` + 그림자. 첫 카드는 꿀색 그라디언트(primary), 나머지는 종이+얇은 선. 각 카드 서브카피는 Gaegu:
  - 새 책 만들기 → `새 이불 깔고 시작하기`
  - 최근 작업 이어쓰기 → `덮어둔 이불 다시 펴기`
  - 작업 파일 불러오기 → `다른 굴에서 가져오기`

### 3-2. 도구막대 (`ToolRail.tsx` / `.tool-*`)
- `.tool-rail` 배경 `linear-gradient(180deg,#3d2c1c,#2c1e12)`.
- `.brand-mark` → 꿀색 라운드 배지 안에 "굴 입구" 실루엣(반원+점).
- `.tool-button`: 아이콘+라벨(Jua/700). **활성** = `background: rgba(234,165,60,.16)`, 아이콘·라벨 `#f6c874`, 왼쪽에 꿀색 4×26 둥근 바(`::before` 그대로 활용, 색만 `--honey`).
- 아이콘은 **기존 lucide-react 그대로 유지**(BookOpenText/Palette/ImagePlus/MessageCircleMore/LayoutTemplate/TextQuote/Download). 새로 그리지 말 것.

### 3-3. 인스펙터 (`Inspector.tsx` / `.panel-*`, `.inspector-section`, `.field`)
- `.inspector` 배경 `--paper-2`, 우측 `1px solid var(--line)` + `--shadow-float`.
- `.panel-header h2` → `font-family: "Jua"`, 우측에 Gaegu 힌트 문구(예: 테마=`이불 고르기`, 지면=`폭신하게`).
- **섹션을 카드화**: 기존 `<details.inspector-section>`를 라운드 카드(`background: var(--paper); border:1px solid var(--line); border-radius: var(--radius-lg); padding:15px; box-shadow: var(--shadow-card)`)로. 섹션 타이틀 Jua 14px.
- `.field input/select/textarea`: `border-radius: var(--radius-sm)`, focus 시 `border-color: var(--honey); box-shadow: 0 0 0 3px rgba(234,165,60,.18)`.
- 버튼: primary=꿀색 그라디언트, secondary=흰 배경+얇은 선(hover `border-color: var(--honey)`), danger=`#fff5f2/#a94b30`.
- 테마 행(`.theme-row`): 활성 시 `border-color: var(--honey)` + 체크 아이콘 꿀색.

### 3-4. 책 지면 (`BookCanvas.tsx` / `.book-page`)
- **거의 그대로 유지.** 테마 시스템(`themes.ts`), 텍스처, 스마트 하이라이트(인용=`quoteColor`, 괄호=`bracketColor` italic), 페이지 자동분할 모두 유지.
- 변경점만:
  - `.book-page.is-selected` 아웃라인 `--accent` → **`--honey`**.
  - `box-shadow`를 `--shadow-float` 계열로 살짝 부드럽게, `border-radius: 6px` 유지.
  - `--page-font`에 `"Noto Serif KR"` 폴백 추가.
- 작업공간 배경(`.workspace-shell`)은 `--sand` + 미세 도트(`radial-gradient(circle, rgba(90,70,45,.10) 1px, transparent 1.4px)` 15px).

### 3-5. 마스코트 & 헤더
- `.mascot-message` 폰트 `Gaegu`, 배경 `rgba(255,253,248,.96)`. 스프라이트/애니메이션 유지.
- `.workspace-header` 반투명 크림 `rgba(252,245,230,.86)` + `backdrop-filter: blur(10px)`, 저장됨 아이콘 색 `--leaf`.

## 4. 반응형
기존 `@media (max-width:760px)` 브레이크포인트 구조를 **유지**하고 톤만 새 토큰으로. 확인 포인트:
- 모바일: 도구막대 → 하단 고정 탭바(가로 7칸), 인스펙터 → 바텀시트(슬라이드업), 활성바는 상단 4×26.
- 홈: 무대 1열 스택(제목 위 / 굴 아래), 액션 3개 세로, 우측 필 숨김.

## 5. 카피 말투 (귀엽고 장난스러운 햄스터)
- **기능 UI 라벨은 명료하게**(원고/테마/저장됨 등), **감성 카피만 Gaegu + 햄스터 말투**로.
- 토스트 예시: `'푸른 시각' 이불을 덮었어요!`, `새 이불을 폈어요. 첫 문장을 적어볼까요?`, `모든 페이지에 발도장을 찍었어요!`
- 멤버 샘플명: `토실이`, `밤톨이`. 씨앗/이불/굴 은유 일관 사용.
- **이모지는 시스템 UI에 넣지 말 것.** 귀여움은 손글씨체·라운드·마스코트·CSS 씨앗 모양으로.

## 6. 마이크로 인터랙션
- 전환 이징 `cubic-bezier(.2,.8,.2,1)`, 200–260ms.
- 카드/버튼 hover: `translateY(-3px)` + 그림자 강화.
- 램프 글로우 `glowpulse` 4s, 씨앗 `seedfloat` 5–7s, 진입 `risein`.
- 바텀시트 `transform: translateY()` 슬라이드, 테마 변경 시 지면 색 트랜지션.
- `@media (prefers-reduced-motion: reduce)` 블록 유지.
